# Fair Benchmark: 6-Method Deconvolution Comparison

## Overview

This benchmark evaluates spatial transcriptomics deconvolution methods under
**fair conditions**: ALL methods receive the SAME `spatial_adata.h5ad` (raw counts)
per dataset. No legacy paths, no per-method preprocessing.

**Core principle: SeedTopic is ONE model.** Ref-based and ref-free differ ONLY in seed derivation.

**Methods compared (6 total):**
- **FlashDeconv** — fast non-negative least squares deconvolution (reference-based)
- **RCTD** — robust cell type decomposition, full mode (reference-based)
- **MarkerScore** — DE marker gene scoring with softmax (reference-based)
- **STAMP** — unsupervised spatial topic model (no reference, Hungarian matching for eval)
- **SeedTopic ref-based** — seed-guided neural topic model with reference-derived seeds
- **SeedTopic ref-free** — seed-guided neural topic model with Leiden+ChatGPT-derived seeds

**Datasets:**

| Dataset | Platform | K (types) | Spots |
|---------|----------|-----------|-------|
| visium_NPC | Visium | 7 | ~3k |
| xenium_BC | Xenium | 19 | ~100k |
| visiumHD_CRC_I | Visium HD | 5 | ~40k |
| visiumHD_CRC_II | Visium HD | 6 | ~40k |

## Reproduction Steps

The full pipeline runs from raw data to final results:

```bash
# Step 0: Clean previous results (ALWAYS do this first)
bash experiments/benchmark_fair/clean_results.sh

# Step 1: Copy raw data to local directory (run once)
bash experiments/benchmark_fair/copy_raw_data.sh

# Step 2: Preprocess raw → processed (run once, in seededntm env)
micromamba activate seededntm
python experiments/benchmark_fair/preprocess_data.py --all

# Step 3: Run unit tests to verify correctness
pytest experiments/benchmark_fair/test_benchmark_correctness.py -v

# Step 4: Run ablation to select universal representation/prior (first time only)
bash experiments/benchmark_fair/run_ablation.sh
# Then analyze: python experiments/benchmark_fair/run_rep_prior_ablation.py --analyze

# Step 5: Run the full benchmark (on GPU node, after setting ablation-selected config)
bash experiments/benchmark_fair/run_benchmark.sh
```

## Preprocessing Details

The `preprocess_data.py` script performs dataset-specific preprocessing:

### visium_NPC (K=7)
- Filter genes (min_cells=3), select 5000 HVGs (seurat_v3)
- Ground truth: argmax of proportion columns in sp.obs.csv
- Reference subset to: B, Myeloid, T, Treg, fibroblast, normal, tumor

### xenium_BC (K=19)
- Assign cell types from Cell_Barcode_Type_Matrices.xlsx, drop Unlabeled
- Filter cells (min_genes=5), filter genes (min_cells=5)
- Reference built from 10x h5 + MOESM4 annotations, subset to 19 types

### visiumHD_CRC_I (K=5) and visiumHD_CRC_II (K=6)
- Ground truth from DeconvolutionLabel1_name in metadata
- Remove QC_Filtered and non-target spots
- Filter genes (min_cells=3), require ≥10 spots per cluster
- Select 5000 HVGs (seurat_v3)
- Shared reference (32 types) subset to K target types

### Seed Derivation
Seeds are derived uniformly across all datasets:
- Wilcoxon rank-sum test on normalized reference (scanpy rank_genes_groups)
- Top 20 marker genes per cell type
- Sorted alphabetically by cell type, indexed 0..K-1

## Metrics

All methods are evaluated on the same spot set with the following metrics:

| Metric | Description |
|--------|-------------|
| F1 | Macro-averaged F1 score (argmax assignment) |
| Precision | Macro-averaged precision |
| Recall | Macro-averaged recall |
| AMI | Adjusted Mutual Information |
| ARI | Adjusted Rand Index |
| AUPRC | Area Under Precision-Recall Curve (proportions vs one-hot) |
| Pearson | Pearson correlation (flattened proportions vs one-hot) |
| Spearman | Spearman correlation |
| RMSE | Root mean squared error |
| JSD | Mean Jensen-Shannon divergence per spot |

## Fairness Guarantees

1. **Same spatial data** — ALL methods receive `processed/{dataset}/spatial_adata.h5ad` (raw counts). No legacy paths. No per-method preprocessing.
2. **Same K-type reference** — Reference-based methods receive the reference subsetted to exactly the K target cell types present in ground truth.
3. **Same spots evaluated** — Primary metrics use all spots. RCTD-filtered subset metrics also reported.
4. **Identical metrics computation** — `compute_metrics()` for named methods; `compute_metrics_hungarian()` for STAMP.
5. **No per-dataset hyperparameter tuning** — Universal (representation, prior) config selected by ablation.
6. **Reproducible** — Fixed seeds, deterministic CUBLAS, versioned inputs, provenance logging, unit tests.

## Final Benchmark Results (F1, macro-averaged)

| Method | visium_NPC | xenium_BC | visiumHD_CRC_I | visiumHD_CRC_II |
|--------|-----------|-----------|----------------|-----------------|
| FlashDeconv | 0.531 | 0.556 | 0.815 | 0.707 |
| RCTD | 0.306 | 0.665 | 0.824 | 0.733 |
| MarkerScore | 0.500 | 0.519 | 0.698 | 0.592 |
| STAMP | 0.335 | 0.416 | 0.510 | 0.138 |
| SeedTopic (ref) | 0.472 | 0.641 | 0.514 | 0.398 |
| SeedTopic (ref-free) | 0.429 | 0.543 | 0.534 | 0.259 |

**SeedTopic configuration:**
- Representation: `idf_lev_seed_spec` (ablation winner, avg rank #1 across 4 datasets)
- Prior mode: `standard` (ablation winner)
- Evaluation: direct matching (argmax) for all seeded/named methods; Hungarian matching ONLY for STAMP

**Key bug fix (prior column ordering):** `compute_topic_prior()` and `compute_topic_prior_idf()`
in `seededntm/util.py` now index columns by `topic_index` from the seed file, not by dict
iteration order. Dict order can differ from `topic_index` when seed files have non-alphabetical
key ordering, which caused silent column permutation in the prior matrix.

## Ablation: Selecting Universal Config

Before the final benchmark, run the ablation to determine the best (representation, prior_mode):

- 3 representations × 3 prior modes = 9 configs
- 9 configs × 4 datasets = 36 experiments
- Metrics: F1, Precision, Recall, AMI, ARI, AUPRC
- Selection: average **rank** across all metrics × datasets (lowest = best)
- **Winner:** `idf_lev_seed_spec` + `standard`

```bash
# Run ablation
bash experiments/benchmark_fair/run_ablation.sh

# Analyze results (prints winner)
python experiments/benchmark_fair/run_rep_prior_ablation.py --analyze
```

The ablation winner (`idf_lev_seed_spec` + `standard`) is set in `SEEDTOPIC_CONFIG` in `run_fair_benchmark.py`.

## Prerequisites

Two conda/micromamba environments are required:

1. **transpa** — for FlashDeconv, RCTD, and MarkerScore
   - `flashdeconv>=0.1.6`
   - `rctd-py>=0.3.2`
   - `scanpy`, `torch`

2. **seededntm** — for SeedTopic, STAMP, and preprocessing
   - SeedTopic package (this repo)
   - `sctm` (scTM for STAMP)
   - `squidpy` (spatial neighbors for STAMP)
   - `scanpy`, `torch`, `pyro-ppl`, `openpyxl`

## Conventions

- Never set `CUDA_VISIBLE_DEVICES` — use `--device cuda` (defaults to cuda:0)
- ALWAYS clean results before running (`clean_results.sh`)
- ALWAYS run unit tests before experiments
- Results are written with fcntl file locking for parallel safety
- `use_nb_obs=True` ALWAYS — this is a canonical, immutable hyperparameter
- No conditional hyperparameters — universal config for all datasets
